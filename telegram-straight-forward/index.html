Straight Forward

Broadcast a message to several private chats 33% faster, without jumping through hoops.

Role
Product designer
Company
Telegram (opens in a new tab)
When
October 2026

Problem

Telegram users often want to share personal updates, photos, or memories with several friends, family members, or colleagues individually, without creating a group chat.

However, Telegram’s existing workflow introduces unnecessary friction:

  • Too many steps: Users must send a message to one person, then select and forward it to others.
  • Unwanted attribution: Forwarded messages display a “Forwarded from” label by default, making a message feel less personal. Removing it requires additional actions.
  • Fragmented photo sharing: Message attachments are limited to 10 photos, making large collections cumbersome to select and forward.

Research

I interviewed 8 Telegram users from my personal network, exploring their experiences with the app and asking 3 groups of questions:

  • When was the last time you shared the same content with multiple people individually? Did you share text, photos, videos, or files?
  • Can you walk me through how you shared it, step by step?
  • Can you recall receiving a message with a “Forwarded from” label showing the sender’s own name? What did you think of it? Have you ever sent a message like that yourself, and did you do anything about the label?
FindingObservationAction
Sharing habits The most common use cases were sharing vacation and family photos, followed by sending holiday greetings for national and religious celebrations. Support multi-recipient sharing for both messages and photo collections.
Self-forwarding perception Most participants felt uncomfortable receiving messages labeled as forwarded from the sender themselves. Very few knew that forwarding attribution could be removed. Automatically remove forwarding attribution when sending original content to multiple recipients.
Photo-sharing friction Several participants found it inconvenient that forwarded photos were split into multiple messages. Integrate direct multi-recipient sharing into the photo-sharing workflow.

Design

Long-pressing a sent message opens a menu with the familiar Forward option. The same gesture on the Send button opens a menu with enough room for that same option — a natural entry point for Straight Forward.

Telegram’s existing Forward option opens a sheet where, to choose several recipients, the user first has to tap the Select button. With Straight Forward, tapping Select can be skipped. The recipient of the chat where the new message was written is already preselected, so the user can quickly add more recipients.

With Telegram’s existing Forward option, hiding the sender’s name is a separate manual step. Straight Forward hides it automatically when the message is sent.

Finally, the same Forward option can be added to the Send button that appears after attaching images, so photos can be shared with several people as easily as text.

Shipped

Telegram Designers set one rule for their contest: no static mockups. Submissions had to be working, ready-to-implement code, shown in action in a demo video.

I accepted the challenge. I pulled the source code of Telegram’s iOS app from GitHub and, with the help of Claude Code, implemented the design directly in it.

Results

To validate the design, I ran a moderated usability test of the working build with the same 8 participants from the research interviews.

First, with no hints, participants had to find a new way to send the same message directly to several people. 7 of 8 participants found Straight Forward on their own.

Then they completed three sharing tasks twice, once with and once without Straight Forward, while I timed each attempt:

Share with multiple recipientsForwardStraight ForwardTime saved
Text message 18 s 14 s 22%
One photo 23 s 17 s 26%
Large photo batch 43 s 25 s 42%
Average 28 s 18.7 s 33%

On average, sharing was 33% faster with Straight Forward. The biggest gain came where the old flow struggles most: large photo batches were shared 42% faster.

Besides having a lot of fun in the process, 6 of 8 participants were particularly curious to know when the feature would go live. I’ve submitted the design to the contest, so hopefully their curiosity will be satisfied soon.

Learnings

From idea to working feature, as one person. Before moving into UX/UI design, I built mobile apps as a software engineer, so writing code wasn’t new to me. What was new was the pace: with Claude Code, I went from an idea to a working feature inside Telegram’s large codebase without switching hats, keeping my focus on the design decisions.

And I truly enjoyed it. It’s a special feeling to change an app used by a billion people every month, myself included.
